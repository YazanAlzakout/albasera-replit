# AlBasera Player on Replit

This project keeps its existing Expo 54 and React Native TVOS setup.

## Run in Replit

The `Start application` workflow runs:

```bash
npm run web:replit
```

This starts Expo's web development server on port 5000 for the Replit preview.

Native Android, Android TV, iOS, and tvOS builds continue to use the existing scripts in `package.json`.
